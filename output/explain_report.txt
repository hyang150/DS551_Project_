############################################################
# Q1_50day_MA: 50日均线 (Window Function)
# Focus: Vectorized Execution
############################################################

SQL:
SELECT
                Date, Symbol, Close,
                AVG(Close) OVER (
                    PARTITION BY Symbol
                    ORDER BY Date
                    ROWS BETWEEN 49 PRECEDING AND CURRENT ROW
                ) AS MA_50
            FROM stock_data
            ORDER BY Date DESC
            LIMIT 100

--- Internals → Application Mapping ---
DuckDB: STREAMING_WINDOW operator 按 2048-tuple chunk 批量计算 AVG，利用 SIMD 指令加速。
MySQL: 逐行迭代 window frame，每行独立计算，function call overhead 高。

# Q2_daily_volatility: 每日波动率 — Narrow Projection (只读 3 列)
# Focus: Columnar Storage — Column Pruning
############################################################

SQL:
SELECT
                Date,
                Symbol,
                ROUND((High - Low) / Close * 100, 4) AS daily_volatility_pct
            FROM stock_data
            ORDER BY daily_volatility_pct DESC
            LIMIT 100

--- Internals → Application Mapping ---
DuckDB: 列存只读 High/Low/Close 三列的 column segment，跳过 Open/Volume/Symbol/Date，I/O 减少 ~57%。
MySQL: 行存必须读取整行再丢弃不需要的列。

############################################################
# Q3_annual_summary: 年度汇总统计 (GROUP BY + 多聚合)
# Focus: Vectorized Aggregation
############################################################

SQL:
SELECT
                YEAR(Date)   AS Year,
                Symbol,
                ROUND(AVG(Close),  2) AS avg_close,
                ROUND(MAX(High),   2) AS year_high,
                ROUND(MIN(Low),    2) AS year_low,
                SUM(Volume)           AS total_volume
            FROM stock_data
            GROUP BY YEAR(Date), Symbol
            ORDER BY Year, Symbol

--- Internals → Application Mapping ---
DuckDB: PERFECT_HASH_GROUP_BY / HASH_GROUP_BY operator，对 vector chunk 内数据批量 hash + aggregate。
MySQL: 逐行读取 → hash → 更新聚合状态，cache miss 率高。

# Focus: Vectorized Window + STDDEV

                Date, Symbol, Close,
                ROUND(

                        PARTITION BY Symbol
                        ORDER BY Date
                        ROWS BETWEEN 19 PRECEDING AND CURRENT ROW
